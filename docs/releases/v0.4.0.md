# v0.4.0 — Upcoming concerts for your Navidrome library

The first public release discovers concerts for artists in the accessible music
library and presents them in a private offline dashboard and month calendar.

## Included

- Optional SeatGeek, Skiddle and Ticketmaster Discovery adapters, plus automatic
  supplementary MusicBrainz event lookups.
- Venue/location, original event links, provider status and attribution, with
  conservative cross-source deduplication enabled by default.
- Configurable complete-search single exact-name matching and manual provider-ID
  overrides. Ambiguous and truncated searches remain unresolved.
- Persistent per-provider budgets, resumable pagination, backoff and cached results
  retained through failed refreshes.
- Bright, dark and black themes, local ICS export, and optional ntfy, CalDAV and
  Google Calendar integrations.

## Fixes from the local test builds

- Candidate searches now proceed to concert retrieval when an eligible unique
  exact-name match is accepted. Existing v0.3 single candidates are rechecked under
  the existing quota before adoption.
- Pagination keeps one date window across midnight and rejects repeated or
  inconsistent pages instead of publishing incomplete snapshots.
- Ongoing date ranges stay visible; newer reschedules can supersede older listings
  before display-window filtering.
- Invalid settings preserve good state/reports. Matching preferences no longer
  erase authorized provider caches or reset daily counters.
- Persisted provider revisions recover reports after interrupted publication.
- Removed unused release selectors, album ownership checks, album artwork fetching
  and obsolete release-only test harnesses.

## Install or upgrade

Download `navidrome-upcoming-concerts-plugin.ndp`, copy it into Navidrome's plugins
folder, rescan plugins, then grant one user and the intended libraries. Enable only
the providers you want and supply your own credentials in their masked settings.
SeatGeek and Skiddle do not require a Ticketmaster key.

**For v0.3 test installations, keep all plugin storage files.** Replace only the
package. Do not reset caches/counters or rescan your audio just to upgrade.

The release includes the plugin, a reviewed source bundle and `SHA256SUMS`.
See the repository's installation guide for file access and upgrade details.

## Validation and limits

Tested with Navidrome 0.64.2, Go 1.25.4, TinyGo 0.40.1 and Extism Go PDK 1.1.3.
Checks include native race/static tests, real WASM host integration, configuration
save/reload, browser layouts and compatibility replay preserving existing calendar
identities. Tests use fictional provider services and do not certify complete live
coverage or real calendar accounts.

Coverage remains incomplete. Names can refer to different artists, unknown metadata
is preserved, ambiguous duplicates can remain visible, and geographic filtering
and official-site extraction are not implemented. Skiddle use is personal and
non-commercial with its source attribution and original links retained.
