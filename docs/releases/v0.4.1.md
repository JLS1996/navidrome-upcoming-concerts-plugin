# v0.4.1 — Concert scan and calendar fixes

- The dashboard and ICS keep cached provider concerts visible during
  direct-credit rescans. Manual refresh reaches each configured provider, and
  healthy sources stay available when a provider cache needs recovery.
- The dashboard hides cached results when current access cannot be verified,
  including when settings contain a typo. Local scans continue if the
  integration cache needs recovery.
- Multi-day shows appear on each day in the dashboard calendar. The selected
  day's listings keep their own details and source attribution even when URLs
  are shared or missing. Undated shows remain in the uncertain-date list.
- Google Calendar receives the full date range and cancellation status. Existing
  managed events are updated using their current IDs. Calendar sync checks
  ownership before removing an unconfirmed event and defers removals while
  MusicBrainz lookups fail.

Replace the installed `navidrome-upcoming-concerts-plugin.ndp` and rescan
plugins or restart Navidrome. Keep plugin storage to preserve your scan caches,
provider quotas and calendar sync records. The release includes the installable
package, source ZIP and `SHA256SUMS`.

The validation suite targets Navidrome 0.64.2 and uses fixture providers and
calendar services.
