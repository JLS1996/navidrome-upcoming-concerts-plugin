# v0.6.0 — Country filters and concert links

- Switch between Agenda and Calendar with full-width controls. The count sits
  beside the date window. Open **Export calendar** below the month grid to
  download the full report.
- Filter by countries present in the report. Listings with missing venue
  countries remain visible under **All countries**.
- Open a show title to visit its highest-priority available listing. Merged
  shows list their sources in Ticketmaster, SeatGeek, MusicBrainz, Skiddle order
  below the show details. Each linked artist opens its official homepage from
  MusicBrainz.
- Treat the country name Canada and the code CA as the same country when
  comparing listings. Read the venue or event country from Skiddle when supplied.

Replace the installed `navidrome-upcoming-concerts-plugin.ndp` and rescan plugins
or restart Navidrome. Keep plugin storage to preserve scan caches, provider
quotas and calendar state. Reopen `upcoming-concerts.html` after the report is
regenerated. Artist links appear as MusicBrainz lookups complete.
